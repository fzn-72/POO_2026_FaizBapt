# Alterdune

**A console-based role-playing game developed in C++**

## Overview

Alterdune is a console-based role-playing game inspired by Greek mythology, developed as a two-person academic project.

The game features turn-based combat, an inventory system, consumable items, and different types of enemies, including bosses. It uses an object-oriented architecture to organize the game's entities and mechanics.

## Features

- Turn-based combat system
- Player and enemy management
- Multiple enemy types, including mini-bosses and bosses
- Inventory and consumable items
- Randomized combat damage
- Enemy encounters and different possible actions
- Game statistics
- External data loading from CSV files

## Technologies and concepts

- **Language:** C++
- **Programming:** Object-oriented programming, inheritance and polymorphism
- **Data:** CSV file handling

## Project structure

- `.cpp` files contain the class implementations and game logic.
- `.h` files define the classes and their interfaces.
- `items.csv` contains item data.
- `monsters.csv` contains enemy data.

## Getting started

To run the game, compile the C++ source files using a compatible C++ compiler and run the resulting executable from the directory containing the CSV files.

The exact compilation command depends on the project configuration and compiler.

## Context

Academic project developed in a team of two.
